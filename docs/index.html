FEATURES

一个页面，看全整个期权账本

从行情、下单测算到持仓盯市与组合分析，不用来回切换工具，也不必把数据交给第三方。

实时 T 型报价

认购 / 认沽并列展示最新价、涨跌幅、IV、Delta、成交量与持仓量，实值合约与平值行高亮，按到期月切换。

行情内一键试算

点击价格右上角 ∑ 直接弹出该合约收益测算：盈亏、收益率、保证金、盈亏平衡价与迷你盈亏曲线，即时可调。

持仓与平仓管理

支持买入 / 卖出开仓、部分平仓、自定义现价盯市；逐腿计算浮动盈亏、收益率、Delta 与保证金。

组合盈亏曲线

按最新行情逐腿盯市，同时给出到期盈亏与按 IV 重估的当前理论盈亏，并标注盈亏平衡点。

贡献与分组汇总

各持仓盈亏贡献双向条形图，按标的分组汇总 Delta 市值、保证金与市值，盈亏来源一目了然。

完全本地 · 零依赖

仅用 Python 标准库，无需 pip install；行情缓存与持仓存于本地 SQLite，无账号、无云端上传。

i

为什么这个页面只是介绍页？

应用需要一个 Python 后端：抓取实时行情、用 Black-Scholes 模型反推 IV 与 Greeks、计算保证金并读写本地持仓。而 GitHub Pages 只能托管静态文件，无法运行后端，所以线上这里是一个纯静态落地页，不会尝试启动项目或请求任何接口。要真正使用功能，请在本地一键启动（下方三步），或把整套服务部署到自己的服务器。

GET STARTED

三步，在自己的机器上跑起来

只需要 Python 3.8+，无需安装任何依赖包。

1

获取源码

克隆仓库或下载压缩包，解压到任意目录。

2

启动服务

执行 python app.py，标准库自带 Web 服务即刻就绪，可用 PORT / HOST 调整监听地址。

3

打开浏览器

访问 localhost:8765，行情会自动加载；录入持仓后即可看到组合盈亏曲线。
